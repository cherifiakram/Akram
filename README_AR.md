# مشروع Football Draft للأندرويد

هذا المشروع يغلّف نسخة اللعبة الحالية داخل تطبيق Android بسيط باستخدام WebView. ملف اللعبة موجود في `app/src/main/assets/index.html`.

## أسهل طريقة لبناء APK مجانًا عبر GitHub
1. حمّل ملف ZIP وفك الضغط عنه.
2. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات المجلد إليه (وليس ملف ZIP نفسه).
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build Android APK** ثم اضغط **Run workflow**. ويمكن أن يبدأ البناء تلقائيًا بعد رفع الملفات إلى فرع `main`.
5. بعد نجاح العملية، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
6. حمّل `football-draft-apk`، ثم فك ضغطه لتحصل على `app-debug.apk`.
7. انقل `app-debug.apk` إلى هاتف Android وافتحه. قد تحتاج إلى السماح بالتثبيت من هذا المصدر.

## البناء محليًا عبر Android Studio
افتح هذا المجلد كمشروع في Android Studio، ثم انتظر مزامنة Gradle واختر **Build > Build APK(s)**. هذا المشروع يحتاج اتصال إنترنت أول مرة لتنزيل أدوات البناء.

ملاحظة: الملف الناتج من GitHub سيكون APK تجريبيًا موقّعًا بمفتاح debug، مناسبًا للتثبيت والتجربة وليس للنشر الرسمي على المتجر. لم يتم اختبار البناء بعد في هذه البيئة.
